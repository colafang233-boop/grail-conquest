# Grail Conquest

A browser-first, turn-based strategy prototype inspired by Holy Grail War mechanics: Master–Servant contracts, mana economy, command seals, hidden identities, and hex-grid tactical combat.

> This repository currently uses placeholder shapes and original technical assets only. Existing franchise names and characters are used as temporary design references during prototyping and are not intended for commercial distribution.

## Planned stack

- TypeScript
- React
- Phaser
- Vite
- Vitest
- pnpm workspace

Development work is tracked through pull requests. The first vertical slice focuses on a deterministic command → event → reducer movement pipeline.
